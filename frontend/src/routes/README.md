# Routes

FraudLens uses **TanStack Router** file-based routing with Vite in a pure Single Page Application (SPA) architecture. Every `.tsx` file in this directory defines a route segment. The root layout is `src/routes/__root.tsx`.

## Conventions

| File                     | URL                                                     |
| ------------------------ | ------------------------------------------------------- |
| `index.tsx`              | `/`                                                     |
| `dashboard.tsx`          | `/dashboard`                                            |
| `analyze.tsx`            | `/analyze`                                              |
| `transactions.tsx`       | Layout route for `/transactions`                        |
| `transactions.index.tsx` | `/transactions` (list view)                             |
| `transactions.$id.tsx`   | `/transactions/:id` (e.g. `/transactions/DEMO-TX-104921`)|
| `alerts.tsx`             | `/alerts`                                               |
| `models.tsx`             | `/models`                                               |
| `explainability.tsx`     | `/explainability`                                       |
| `drift.tsx`              | `/drift`                                                |
| `research.tsx`           | `/research`                                             |
| `settings.tsx`           | `/settings`                                             |
| `__root.tsx`             | Root shell wrapping all routes with `<Outlet />`        |

`src/routeTree.gen.ts` is automatically generated by `@tanstack/router-plugin/vite`. Do not edit it manually.

## Static Hosting & SPA Fallback

Because FraudLens Frontend is a client-side SPA, direct URL navigation or browser refreshes on nested routes (e.g., `/transactions/DEMO-TX-104921` or `/analyze`) require static hosts to rewrite non-file requests to `/index.html`:

- **Vite Preview / Dev**: Handled automatically.
- **Nginx**: `try_files $uri $uri/ /index.html;`
- **Caddy**: `try_files {path} /index.html`
- **Netlify**: `/*    /index.html   200` in `public/_redirects`
- **Vercel**: `rewrites: [{ "source": "/(.*)", "destination": "/index.html" }]` in `vercel.json`
